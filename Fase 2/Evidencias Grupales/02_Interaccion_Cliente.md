# Evidencia: Interacción del cliente

Funciones trabajadas:
- Selección por tap/click.
- Paneo por drag.
- Zoom por rueda.
- Zoom por gesto de pellizco.
- Culling de entidades.
- Marcadores según tipo de entidad.

Estas funciones convierten el cliente desde un visor técnico de estado a una base de interacción jugable.
