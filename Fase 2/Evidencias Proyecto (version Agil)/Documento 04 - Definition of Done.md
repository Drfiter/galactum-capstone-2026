# Definition of Done

Una funcionalidad se considera terminada cuando:
1. El código está integrado sin romper el proyecto.
2. La funcionalidad respeta el contrato vigente.
3. Se ejecutaron las pruebas aplicables.
4. No existen errores críticos conocidos.
5. La documentación relevante fue actualizada.
6. El cambio puede ser reproducido por otro integrante.
7. No se versionan credenciales, claves ni datos personales sensibles.
8. Existe evidencia verificable: commit, test, captura, demo o documento técnico.
