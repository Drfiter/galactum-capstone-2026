# Definición pública del Proyecto APT

## Proyecto
**Galactum — Sistema de Mundo y Combate en Tiempo Real (Equipo 3)**

## Integrantes
- Lucas Orellana
- Mateo Orellana

## Área de desempeño
- Desarrollo de Software
- Arquitectura de Sistemas Distribuidos
- Desarrollo de Videojuegos

## Objetivo general
Desarrollar e implementar el sistema de mundo persistente en tiempo real (SSS) y el módulo de combate determinista para Galactum, integrando arquitectura cliente-servidor con WebSocket, optimización espacial y resolución de combate.

## Metodología definida
- Scrum.
- Sprints de 2 semanas.
- Reuniones periódicas.
- Git/GitHub con ramas por funcionalidad.
- GitHub Projects / Kanban.
- TDD para componentes críticos.

## Privacidad
Los RUT y otros datos personales sensibles de la guía original fueron omitidos de esta versión pública.
