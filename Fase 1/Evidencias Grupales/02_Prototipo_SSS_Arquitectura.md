# Evidencia: Prototipo SSS + Arquitectura

## Objetivo
Validar la comunicación técnica entre un cliente Godot y el Servidor de Sistema Solar (SSS).

## Evidencia técnica
- Cliente Godot.
- SSS ejecutado como proyecto Godot headless.
- WebSocket JSON.
- Puerto local 9100.
- Mapa de pruebas 600×600.
- Snapshot inicial del mundo.
- Manejo de secuencias y tiempo de servidor.

## Resultado
La base Cliente ↔ SSS fue validada y utilizada como fundamento para los hitos posteriores.
